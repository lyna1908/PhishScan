# PhishScan Browser Extension

This extension sends email content to the PhishScan interface and opens detailed analysis automatically.

## Load extension in Chrome/Edge
1. Open `chrome://extensions` or `edge://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this folder: `extension`.

## Use
1. Open the extension popup.
2. Set `Interface URL` (for example `http://localhost:5000`).
3. Paste sender, subject, and email body.
4. Click **Open Detailed Analysis**.

The interface opens with prefilled fields and runs analysis automatically.
